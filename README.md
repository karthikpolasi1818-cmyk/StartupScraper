# StartupScraper

A Python web scraping project that collects startup and tech news headlines from Hacker News and exports structured data to CSV and JSON.

## Features

- Scrapes news headlines
- Extracts article URLs
- Removes duplicate records
- Exports data to CSV
- Exports data to JSON

## Technologies Used

- Python
- Requests
- BeautifulSoup4
- Pandas

## Installation

pip install requests beautifulsoup4 pandas

## Run

python scraper.py

## Output Files

- startup_news.csv
- startup_news.json
